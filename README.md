## About this repository

A static site written in plain HTML, CSS and JavaScript, with no build step or dependencies. It is published with GitHub Pages straight from the `main` branch.

To preview locally, open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
```
